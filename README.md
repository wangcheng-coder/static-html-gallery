# 好看的静态 HTML

收集可以直接打开的静态页面：落地页、个人主页、后台壳、动效和成套小练习。每条都写清它适合做什么、先看哪个文件，并跳到 GitHub 源码。

这里只做索引。页面的版权和许可证以原仓库为准。预览方式以原仓库 README 为准。

## 怎么用

1. 按下面的用途打开对应页。
2. 克隆原仓库，用浏览器打开它的 `index.html`，或按它自己的 README 起静态服务器。
3. 要改视觉时，先改颜色、字体和间距，再动结构。

收录标准：

- 主体是 HTML、CSS、JavaScript，克隆后能看到完整页面。
- 组件库单独放在 [页面骨架](css.md)，因为它们是用来搭页面的，不是一整站成品。
- 需要数据库或登录后端才能看到界面的项目不收。
